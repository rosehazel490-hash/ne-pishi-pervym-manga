# Манга «Не пиши первым»

Веб-читалка с русским и турецким интерфейсом. Изображения глав хранятся рядом с сайтом; текст для озвучки можно добавить на каждой странице и прослушать голосом браузера.

## Запуск локально

Требуется Python 3.12 или новее. Выполните `python server.py` и откройте `http://localhost:8080`. Порт можно изменить переменной `PORT`.

## Деплой на Railway

Создайте проект через **Deploy from GitHub repo**, выберите репозиторий и дождитесь сборки `Dockerfile`. Затем в настройках сервиса выберите **Generate Domain**. Сервер слушает `0.0.0.0` и порт из переменной `PORT`, назначенной Railway.

Текст для озвучки сохраняется отдельно для каждой страницы в браузере читателя. Для турецкого интерфейса автоматическая озвучка выбирает локаль `tr-TR`; доступность голоса зависит от браузера и операционной системы.
